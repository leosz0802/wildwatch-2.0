## 触发入口与处理

| 来源 | 本次处理 |
| --- | --- |
| 正在进行的剧情步骤、动物发现线索、现场事件 | 保留有明确行动依据的巡护；覆盖章节剧情指引与真实结算 |
| 严重数值风险 | 统一每日目标、推荐入口、地图通知的风险判断 |
| 每日守护目标 | 状态稳定时走实际物品探索；不再按章节静态动作或上次巡护记录生成巡护 |
| 生态、种群、迁入等普通晋级数值目标 | 不再兜底生成猎犬侦察或栖息地修复 |
| 水草、安全恢复及一般波动通知 | 保留资源反馈，取消后续巡护按钮与任务入口；兼容旧缓存通知 |
| 无有效动作的通用巡护入口 | 不再选择动作列表第一项；显示当前没有巡护现场 |
| 玩家明确选择四类动作 | 保留；取消不消耗，重新打开可执行，重复执行不重复结算 |
| 旧每日任务记录与任务锁 | 每日结构迁移到三项目标；刷新当前推荐后继续，不沿用过期巡护动作 |
| 打开每日任务清单 | 显示清单，保留未完成任务供明确点击继续；不在普通沙盘入口自动弹出旧巡护 |
| 系统自动推送 | 上一次用户或系统任务触发后必须超过 30 秒；恰好 30 秒不触发 |

严重风险阈值：水源或草场 ≤35 对应栖息地修复；疾病 ≥45 对应生态干预；偷猎压力 ≥65 对应边界驱赶；安全 ≤30 对应猎犬侦察。实际剧情和玩家明确操作不受这些自动推荐阈值限制。多个严重指标并存时推荐偏离阈值最多的一项。

## 本轮发现的缺陷

1. 每日守护沿用静态章节动作，且历史侦察记录能转为新的生态干预，稳定状态也会继续生成巡护。
2. 通用入口在无推荐或无效动作时退回猎犬侦察。
3. 数值改善后生成的恢复通知仍能打开巡护，形成处理后再派发的链路。
4. 打开每日清单会直接恢复旧任务；旧任务锁还可能携带过期巡护动作。
5. 每日探索只进入频道而未进入实际探索，计数不变；重复点击会一直回到原入口。

- 四类动作取消后重进、四种旧每日巡护锁、每日三项目标完成与存档重新归一化，检查无重复奖励。
- 顺序与跳跃路由、交错任务、中断恢复、补给不足、系统冷却、剧情指引、章节晋级顺序、数值反馈。
- 非线性运行 4 组 × 32 天，长跑 4 个种子 × 120 天 × 每天 3 次动作；具体输出见 JSON。
- 模拟画布的 320、375、430 宽度界面检查。

以上用例每轮各执行一次，共两轮。20 章覆盖的是巡护操作与剧情/晋级断言，不等同于真人逐章完整游玩。
