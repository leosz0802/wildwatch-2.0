## 结论先行

当前系统已经具备“天气 → 水草 → 动物 → 迁徙/游客 → 基金与干预”的主要结构，但无干预长跑显示出明显的水源枯竭和疾病累积：

- 初始水源 68、草场 56、疾病 12。
- 30 天时水源已降至 15～24，草场升至 92～93。
- 90 天时水源为 0～1，疾病为 78～100。
- 360 天时水源为 0～10，疾病为 78～88；多数种群只剩低数量捕食者和波动的食草动物。
- 所有种子在“不执行有效经营”的跑法下都停留在保护区 1 级，这是进度门槛的预期结果；生态状态则已经进入长期危机，而不是可恢复的周期震荡。

最容易崩溃的节点是：

```text
旱季水源下降
→ 加权动物消耗继续扣水
→ 水源低于 40 后迁徙外流
→ 水草承载下降、疾病累积
→ 捕食者和食草动物数量波动/下降
→ 生态评分与游客环境因子下降
```

## 缺失参数

下列内容在当前代码中没有找到可直接审计的独立参数，或只有叙事/事件层的局部效果：

| 参数 | 当前状态 | 影响 |
|---|---|---|
| 降雨量（毫米） | 缺失；只有天气类别带来的水源增减 | 无法区分小雨、暴雨的水量守恒 |
| 温度 | 缺失 | 蒸发、疾病和动物热应激无法独立校准 |
| 蒸发量 | 缺失；晴天只以天气分支间接扣水 | 无法建立 `Water(t+1)` 的独立蒸发项 |
| 动物饮水消耗 | 缺失独立物种系数；目前以总量分段扣水 | 无法按物种体型和水依赖度校准 |
| 人类/游客用水 | 缺失 | 游客增长不会消耗水资源 |
| 物种出生率 | 缺失统一比例；个体出生使用 17/31 天节奏和条件 | 无法按物种繁殖策略分别调节 |
| 物种自然死亡率 | 缺失统一种群死亡项；个体死亡在 `emotionSystem` 中按寿命/健康处理 | 种群总量与个体生命史之间仍不完全闭合 |
| 疾病传播率 | 缺失独立传播参数 | 当前疾病主要是水草短板和季节压力的结果 |
| 偷猎基础发生率 | 缺失独立常数；事件和守护日分支间接增加压力 | 难以单独做风险曲线 |
| 门票价格 | 缺失；使用经营能力计算单客贡献 | 收入无法体现票价/消费结构 |
| 保护区固定支出 | 当前逻辑为 0 | 经营闭环没有持续维护资金压力 |
| 独立科技树数值 | 缺失；设施路线专精承担部分科技效果 | 科技成长没有单独模型 |
| 全局游戏速度倍率 | 缺失独立配置；只有守护日和 `activeSeconds` 记录 | 无法从单一参数调整现实时间与游戏时间比例 |

## 2026-09-10 游客、基金与目标闭环

本轮按“游客因子 → 基金维护/用水 → 章节目标与线索入口”的顺序完成：

- `eventEconomy.visitorEngagement()` 拆分水源、草场、疾病三项反馈，并返回 `risk`；游客活动、留存和环境分数会对三项分别响应。

- 沙盘仍由 `goalSystem.buildGoalView()` 提供唯一主目标，目标卡的“立即前往”和“更多线索”入口继续使用同一主目标/机会队列；游客数量和来信仅在变化时显示，避免常驻信息抢占目标卡。
